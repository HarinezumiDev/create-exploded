# Security Policy

## Supported Versions

Create: Exploded is supported only for Minecraft Neoforge 1.21.1 right now.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.2   | :white_check_mark: |
| <1.2.2  | :x:                |

## Reporting a Vulnerability

This mod is maintained only by me, that’s why you can expect some bugs. I test mod before uploading it but I may miss few bugs.
If **you find the bug**, check if you are using the latest mod version. Report it to Issues or to my [Discord server](https://discord.com/invite/ZvM8trgsM7).
If you found a **security vulnerability** (an exploit or a dangerous bug that shouldn't be made public), please don't open a public issue. Report it privately by creating a ticket in the `#create-ticket` channel on my [Discord server](https://discord.com/invite/ZvM8trgsM7).
